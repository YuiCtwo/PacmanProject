## ITPacman Tasks

这里把整个项目拆分为不同的任务~~（其实是方便作者利用碎片时间写实现）~~。

黑色标记的是原 `Berkeley Pacman assignments` 的内容修改和划分后的内容。而红色标记的是我个人（计划）扩展的内容。

虽然名称为 Level，但并不是为了在难度上进行区分。每个 Level 会有不同的侧重点，计划涵盖包括 GUI，设计模式，图形学，计算机视觉，传统算法，人工智能，Agent 等多项内容。借助于“吃豆人”这一题目，来一窥这些技术。

受限于作者的能力（也在学习中），对于以上内容不会过于深入，对于这些领域的深入学习不会包含在本项目内，但会尽可能的包含相关问题的探讨。
